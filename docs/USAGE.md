# 使用指南

## 打开与收起

岛仔常驻在 macOS 菜单栏。鼠标靠近收起的小岛即可展开；移开后自动收起。也可以从菜单栏的岛仔图标打开设置、打开日历、切换吉祥物、设置开机启动、打开数据目录或退出应用。

顶部和底部停靠时用左右箭头或底部圆点切换页面。左侧和右侧停靠时使用对应的翻页按钮。列表内容可以直接滚动。

## 设置

设置窗口分为通用、音乐、提醒、待办与置物、邮箱、日程、页面管理、AI 额度、天气、外观、位置、系统性能和无线设备等页面。

更改会即时保存。页面开关决定对应模块是否在岛上显示以及是否继续在后台工作。

## 凭据与隐私

邮箱授权码、日历密码和独立的 API Key 保存在 macOS 钥匙串。数据目录默认为：

```text
~/Library/Application Support/Daozai
```

设置环境变量 `DAOZAI_DATA_DIR` 可以指定其他目录。完整网络访问说明见 [隐私与安全](PRIVACY.md)。

## 更新

在“设置 → 关于”点击“检查更新”。发现新版本后，通过浏览器下载 ZIP，解压并替换现有 `岛仔.app`。

## 卸载

退出岛仔，将 `岛仔.app` 移到废纸篓。需要彻底清除本机数据时，再删除 `~/Library/Application Support/Daozai`。
